# Desktop-class cross-platform support

SSHWarden will treat Windows 10/11, Linux desktop sessions, and macOS 13+ as first-class supported platforms, meaning each must provide a complete user-facing SSH agent experience rather than merely compiling. WSL, BSD, mobile, browser, and headless server environments are out of scope unless explicitly promoted later, because the product depends on interactive desktop capabilities such as unlock prompts, signing authorization, local agent integration, and startup/session behavior.
